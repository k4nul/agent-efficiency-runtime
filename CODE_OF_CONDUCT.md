# Code of Conduct

## Expected conduct

Participants must keep project communication technical, specific, and respectful. Review code and
ideas rather than the person presenting them. Assume good faith, provide reproducible evidence, and
accept correction when a claim is not supported.

## Unacceptable conduct

The following behavior is not accepted:

- harassment, threats, discrimination, or targeted personal attacks;
- sexualized language or unwanted personal attention;
- publishing another person's private information;
- deliberately disruptive, deceptive, or spam activity;
- repeated off-topic argument after a maintainer has set a project boundary;
- using security reports to pressure, extort, or publicly expose users.

## Scope

This policy applies to repository issues, pull requests, reviews, discussions, release channels,
and other spaces used to represent the project.

## Enforcement

Report conduct concerns privately to the repository maintainer through GitHub. Do not include
sensitive personal information in a public issue. The maintainer may edit or remove content, close
or lock conversations, reject contributions, or restrict participation. Enforcement decisions are
based on the behavior and its effect on the project, not on a participant's status or seniority.
